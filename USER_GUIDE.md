## 🚀 Installation

### Prerequisites
- Google Chrome browser (latest version recommended)
- Access to browser extensions settings

### Installation Steps

1. **Open Chrome Extensions Page**
   - Type `chrome://extensions/` in address bar
   - Or: Menu → More Tools → Extensions

2. **Enable Developer Mode**
   - Find toggle switch in top-right corner
   - Click to enable

3. **Load the Extension**
   - Click "Load unpacked" button
   - Navigate to and select the `/app` folder
   - Extension will appear in your list

4. **Pin the Extension** (Recommended)
   - Click Extensions icon (puzzle piece) in toolbar
   - Find FocusLock
   - Click pin icon to keep visible

## ⚡ Quick Start

### Your First Focus Session

1. **Set Your Name** (Optional but recommended)
   - Click FocusLock icon → Settings (⚙️)
   - Enter your name in "Personal" section
   - Click "Save Settings"

2. **Start a Session**
   - Click FocusLock icon in toolbar
   - Enter what you're focusing on (e.g., "Math homework")
   - Click "Start"
   - Focus page opens automatically

3. **Stay Focused**
   - Your current tabs are saved
   - Timer counts down
   - If you switch tabs, you'll see a warning
   - Blocked sites automatically redirect to focus page

4. **End Your Session**
   - Let timer complete naturally, OR
   - Click "End Session" button to stop early
   - All your tabs will be restored automatically

## 📚 Detailed Usage

### Starting a Focus Session

**From Popup (Quick Start)**:
1. Click FocusLock icon
2. Enter focus topic when prompted (optional)
3. Click "Start"

**From Focus Page (Full Control)**:
1. Click "Open Focus Page" in popup
2. Add tasks if desired
3. Click "Start" button on focus page
4. Enter focus topic if prompted

### Managing the Timer

**Pause**:
- Click "Pause" button
- Timer stops but session remains active
- Click "Start" to resume

**Reset**:
- Click "Reset" button (↻)
- Timer returns to full duration
- Session state returns to idle
- Does NOT restore tabs

**End Session**:
- Click "End Session" button
- Confirm the action
- Timer stops completely
- All tabs are restored
- Session ends

### Using Soundscapes

**Starting a Soundscape**:
1. Select sound from dropdown
2. Click Play button (▶)
3. Adjust volume if needed

**Changing Sounds**:
1. Stop current sound (click Pause)
2. Select new sound
3. Click Play

**Volume Control**:
- Drag slider left (quieter) or right (louder)
- Changes apply immediately
- Setting saved for current session

### Adding and Managing Tasks

**Adding a Task**:
1. Select subject category (Work, Study, etc.)
2. Type task description
3. Click + button or press Enter
4. Task appears at bottom of page

**Completing Tasks**:
- Click ✓ button on task card
- Task gets strikethrough and fades
- Marks your progress

**Deleting Tasks**:
- Click ✕ button on task card
- Task is permanently removed

### Understanding Modes

**Focus Mode** (🎯):
- Main working time
- Strict blocking active
- Tab switches trigger warnings
- Default: 25 minutes

**Short Break** (☕):
- Quick rest period
- No strict blocking
- All sites accessible
- Default: 5 minutes

**Long Break** (🌴):
- Extended rest
- After 4 focus sessions (default)
- No restrictions
- Default: 15 minutes

## ⚙️ Settings Configuration

### Personal Settings

**Username**:
- Your name for greetings
- Appears on focus page
- Optional but recommended
- Can be changed anytime

### Timer Settings

**Focus Duration** (1-120 minutes):
- How long each focus session lasts
- Default: 25 minutes
- Recommended: 25-50 minutes

**Short Break Duration** (1-60 minutes):
- Quick rest period length
- Default: 5 minutes
- Recommended: 5-10 minutes

**Long Break Duration** (1-120 minutes):
- Extended rest period
- Default: 15 minutes
- Recommended: 15-30 minutes

**Long Break After** (1-10 sessions):
- Number of focus sessions before long break
- Default: 4 sessions
- Recommended: 3-4 sessions

### Behavior Settings

**Auto-start Breaks**:
- ✅ Enabled: Break timer starts automatically
- ❌ Disabled: Must manually start break
- Recommended: Disabled (manual control)

**Auto-start Focus After Break**:
- ✅ Enabled: Focus timer starts after break
- ❌ Disabled: Must manually start next session
- Recommended: Disabled (take breaks as needed)

**Strict Mode**:
- ✅ Enabled: Site blocking and tab warnings active
- ❌ Disabled: No blocking, just timer
- Recommended: Enabled for maximum focus

### Notification Settings

**Sound Enabled**:
- Plays alert sounds for warnings
- Includes error.mp3 on tab switches
- Recommended: Enabled

**Browser Notifications**:
- Shows desktop notifications
- Alerts when sessions complete
- Recommended: Enabled

### Blacklist (Blocked Sites)

**Default Sites**:
- facebook.com
- twitter.com
- instagram.com
- youtube.com
- reddit.com
- tiktok.com
- netflix.com
- twitch.tv
- discord.com
- snapchat.com

**Adding Sites**:
1. Type domain (e.g., "twitter.com")
2. Don't include http:// or www.
3. Click "Add" button
4. Site appears in list

**Removing Sites**:
- Click ✕ next to any site
- Site is immediately unblocked

### Whitelist (Always Allowed)

**Purpose**:
- Essential sites that should never be blocked
- Study resources, work tools, documentation

**Adding Sites**:
1. Type domain (e.g., "wikipedia.org")
2. Click "Add" button
3. Site will always be accessible

**Priority**:
- Whitelist overrides blacklist
- If site is on both, it's allowed

### For Maximum Productivity

   - Add YOUR specific distractions
   - Be honest about what wastes your time
   - Update regularly as habits change

5. **Try Different Soundscapes**
   - Experiment to find what works for you

## 🔍 Troubleshooting

### Common Issues

**Extension won't load**:
- Check Developer Mode is enabled
- Verify all files are in /app folder
- Try clicking "Reload" on extension

**Sounds not playing**:
- Check browser isn't muted
- Verify sound enabled in settings
- Try different soundscape

**Focus page not opening**:
- Check pop-up blocker settings
- Allow chrome-extension:// URLs
- Manually open from popup

**Tabs not restoring**:
- Let timer complete or use End Session button
- Don't close Chrome during session
- Check Chrome has tabs permission

## 🎓 Understanding the Psychology

### Why Pomodoro Works
- **Time boxing**: Fixed intervals create urgency
- **Regular breaks**: Prevent mental fatigue
- **Clear start/end**: Makes work feel manageable
- **Focus blocks**: Eliminates multitasking

### Why Strict Mode Helps
- **Removes temptation**: Can't visit distracting sites
- **Creates friction**: Tab switching gets uncomfortable
- **Awareness**: Alerts make you conscious of focus
- **Commitment**: Once started, you're locked in

### Why Soundscapes Matter
- **Masks distractions**: Covers background noise
- **Signals focus time**: Brain associates sound with work
- **Consistent environment**: Same sound = same state
- **Relaxation**: Reduces stress and anxiety
